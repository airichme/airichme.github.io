앤트로픽이 코드를 검사하고 고치고 승인까지 하는 AI 도구를 내놓았어요. 중요한 변경은 사람에게 넘겨요. 승인 기능은 아직 시험 단계예요.

앤트로픽은 23일(현지시간) 코드 검토와 오류 수정, 승인까지 처리하는 AI 도구 '클로드 쉽'을 출시했다고 밝혔다1. 개발자가 코드를 올리면 AI가 오류를 찾아 고친다. 회사가 정한 기준에 맞는 변경은 사람 대신 승인한다. 도구는 세 가지 기능으로 나뉜다. 코드 리뷰는 오류와 보안 문제를 찾는다. PR 스튜어드는 발견된 문제를 고친다. 클로드 어프루벌스는 승인 여부를 판단한다. 회사가 미리 정한 규칙을 충족하면 AI가 직접 승인하고, 중요한 변경은 사람에게 넘긴다2. 코드 리뷰는 정식 제공 중이고 나머지 둘은 베타 단계다5. 베타는 아직 시험 중인 단계를 뜻한다. 앤트로픽은 자체 효과도 내놓았다. 클로드 코드 개발팀이 올해 6월부터 9월까지 정식 반영한 코드 변경 건수는 두 배 넘게 증가했다3. 반영한 코드를 다시 취소한 비율은 40% 이상 감소했다4. 이는 코드 리뷰를 포함한 여러 개발 절차를 활용한 성과라고 회사는 설명했다. 해석 코드를 쓰는 일에 이어 검토와 승인까지 AI가 맡기 시작했다. 개발자의 일이 직접 확인할 변경에 집중하는 쪽으로 바뀔 수 있다. 다만 이 수치는 앤트로픽이 자사 팀에서 밝힌 결과다. 지켜볼 점은 두 가지다. 베타 단계인 PR 스튜어드와 클로드 어프루벌스가 정식 제공으로 넘어가는지 본다5. 또 기업이 AI 승인을 실제 업무에 쓰는지 본다.
