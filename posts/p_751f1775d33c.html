클로드가 만든 앱, 코딩 없이 PC에 설치

쉽게 말하면

앤트로픽이 클로드에게 말로 시키면 PC 프로그램을 만들어 설치해 주는 기능을 내놓았어요. 코딩을 몰라도 돼요. 지금은 시험 단계(베타)이고, 무료 사용자도 쓸 수 있어요.

앤트로픽이 24일(현지시간) 클로드로 만든 프로그램을 PC에 앱처럼 설치하는 기능을 베타로 내놓았다1. 맥과 윈도우가 대상이다. 무료 사용자를 포함한 모든 요금제에서 쓸 수 있다2. 클로드에게 말로 요청해 만든 결과물을 '아티팩트'라고 부른다. 2024년 처음 나온 기능으로, 웹페이지, 차트, 게임, 소프트웨어 등이 여기에 해당한다3. 지금까지는 클로드 안이나 웹 브라우저에서만 실행해야 했다. 이제는 설치해서 일반 프로그램처럼 연다. 패키징, 코드 서명, API 키 발급 절차는 필요 없다4. API 키는 프로그램끼리 연결할 때 쓰는 열쇠 같은 것이다. 제한도 있다. 인터넷 연결과 클로드 로그인이 필요하고, 앱에서 AI를 부르면 기존 요금제의 사용량 한도가 적용된다5. 해석 코딩을 모르는 사람도 필요한 프로그램을 직접 만들어 바로 쓸 수 있는 길이 넓어졌다. 이미 쓰던 상용 소프트웨어를 사는 방식에 영향을 줄 수 있다. 기술 전문 매체 실리콘앵글은 이번 발표가 "AI가 결국 소프트웨어 시장을 집어삼킬 것이라는 주장에 힘을 실어주는 업데이트"라고 평가했다6. 앞으로 볼 점은 베타 기능이 정식으로 나오는지, 그리고 더 많은 사람이 직접 만든 앱을 업무에 쓰는지다.

관리팀 팩트체크 · 팩트체크 확인

F1~F6의 24일 베타 출시, 맥·윈도우, 모든 요금제, 2024년 아티팩트, 패키징·코드 서명·API 키 불필요, 인터넷·로그인 필요, 실리콘앵글 인용이 출처와 일치한다. 본문에 팩트 목록 밖의 사실 주장은 없다.
